Formal Mathematical Definition (Textbook 8-Tuple)

Standard Classical Formalism (with Tape Delimiters & Halting States):
M = (Q, Σ, ⊢, ⊣, δ, qstart, qaccept, qreject)

Q Set of machine states: {q0, q1, q2}
Σ Input alphabet: {0, 1} (where delimiters ⊢, ⊣ ∉ Σ)
⊢ Left Delimiter / Endmarker: Guards left tape boundary. Transition invariant: δ(q, ⊢) = (q', R) (head can never move Left off ⊢)
⊣ Right Delimiter / Endmarker: Guards right tape boundary at cell n+1. Tape contents: ⊢ w1w2…wn ⊣
δ Transition function: (Q \ {qaccept, qreject}) × (Σ ∪ {⊢, ⊣}) → Q × {L, R}
qstart Start state: q0 (head starts on first symbol of w at index 0)
qaccept Halting Accept state: Machine halts immediately with ACCEPT decision
qreject Halting Reject state: Machine halts immediately with REJECT decision

Simulation Engine Mapping (Compact 5-Tuple Model)

Shepherdson (1959) Coordinate Formulation: M = (Q, Σ, δ, q0, F)

Right Boundary Acts as the right delimiter ⊣. When head advances to index n (past input), execution halts. If state ∈ F (q1), string is ACCEPTED; otherwise REJECTED.
Left Boundary Acts as the left delimiter ⊢. If a transition attempts to step left past index 0 (index < 0), tape fall-off occurs; halts immediately and REJECTS.
Cycle Detection If configuration (q, i) repeats, the deterministic machine cycles infinitely. The engine flags LOOP DETECTED (equivalent to halting rejection).
